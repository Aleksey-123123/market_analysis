## 9. Что нужно для следующего шага

1. **Равномерная выгрузка по времени.** Сейчас месяцы — следы фильтров, а не рынок. Чтобы считать динамику, нужна выгрузка с фиксированным фильтром по одинаковым интервалам (например, по одной неделе каждого месяца за 12 месяцев). Это единственный способ проверить гипотезу о сжатии среднего чека.
2. **По-прежнему нет главного.** Четвёртая итерация подряд: **числа участников и снижения цены в выгрузке нет.** Отмены дают прокси риска, но не конкуренции. Пока этого нет, «где мало конкурентов» остаётся непроверяемым — а это центральный вопрос вашей стратегии.
3. **Дедупликация обязательна на входе.** 32,3% строк были повторами. Ключ — «реестровый № + № лота», не только реестровый номер.
4. **Нормализация заказчика.** 8026 «заказчиков» — это юрлица, а не покупатели: Россети = 19 лиц, водоканалы = 65, дорожники = 266. Без склейки крупнейшие покупатели невидимы.

## Оговорки

- **Месячное распределение — артефакт выгрузки, а не сезонность.** Февраль/май/август — отдельные поиски с разными фильтрами по цене, закону и статусу. Сравнение февраль↔май корректно, любое другое — нет.
- Сравнение февраля с маем — **два месяца, а не тренд**, и они различаются позицией в бюджетном цикле.
- В панели февраль/май отмены равны нулю по построению (фильтр «только завершённые»), поэтому по ней отмены не сравнивались.
- «Завершённые» означает завершение процедуры, а не исполнение контракта. Кто выиграл и с каким снижением — нет.
- **522 лота (10,4 млрд ₽) без названия заказчика** — размещены через региональные центры организации закупок. Это крупнейший «заказчик» в массиве и чисто технический артефакт.
- Категории — регулярки по названию лота. «Прочее» — 3689 лотов (12,4% НМЦ) — не разобрано.
- Строки с суффиксом `(N)` в именах файлов GitHub — разные выгрузки, не копии; побайтовый дубль был один.
